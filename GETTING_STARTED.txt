================================================================================
                        TROUBLESHOOTING
================================================================================

SHELL UI WON'T START:
  Q: "command not found: bash"
  A: Make sure you're in the fragle directory:
     cd /home/nisse/fragle

  Q: "Permission denied"
  A: Make script executable:
     chmod +x fragle_tui.sh
     bash fragle_tui.sh

WEB UI WON'T LAUNCH:
  Q: "npm: command not found"
  A: Node.js not installed. Web UI is optional.
     Shell theatre works without it.

  Q: "Port 3000 already in use"
  A: Kill the existing process:
     lsof -i :3000
     kill -9 <PID>
     npm start

LEADERBOARD NOT SHOWING:
  Q: "Scoreboard not found"
  A: Make sure you're in fragle directory:
     cd /home/nisse/fragle
     ./fragle_scoreboard.sh show

  Q: "No activity yet"
  A: Seed test data:
     bash fragle_demo_scoreboard.sh

LOSING SESSIONS:
  Q: "My history disappeared"
  A: Check if logs were cleared:
     ls -la /home/nisse/fragle/.fragle_anon_data/
     ls -la /home/nisse/fragle/.fragle_scoreboard/

  To restore: sessions are per-run. Each entry creates a new UUID.
